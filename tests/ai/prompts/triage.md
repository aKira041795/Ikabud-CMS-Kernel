## How to classify failures

### application-defect
The UI is not rendering expected elements. The test locators are correct but the application is not producing the expected output.
- Missing action button on page
- Missing entity in list
- Wrong status displayed
- Form field not rendered

### test-defect
The test makes incorrect assumptions about the UI.
- Wrong selector for an element
- Expected text that doesn't match actual labels
- Assuming a redirect that doesn't happen
- Testing a feature that doesn't exist yet

### locator-stale
The element exists but the test's locator no longer matches.
- CSS class renamed
- Button text changed
- DOM structure refactored

### environment-issue
The test environment is not properly configured.
- Database not seeded
- Tenant not configured
- Auth token expired
- Server not running

### timing-race
The test is too fast for the application.
- Element exists but hasn't finished rendering
- Alpine.js hasn't initialized
- htmx request hasn't completed
- Page transition animation in progress

### data-state-corruption
The test or its dependencies have corrupted shared state.
- Seed data deleted by another test
- Database transaction not rolled back
- Test ordering dependency
