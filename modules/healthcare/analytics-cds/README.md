# Analytics & CDS

Reporting summaries and clinical decision support rules engine. Subscribes to clinical events to evaluate rules and surface alerts.

## Features

- **CDS rules**: condition-action rules evaluated on clinical events
- **Alerts**: in-workflow alerts surfaced during encounters and ordering
- **Analytics**: aggregated clinical metrics and summaries
- **Event-driven**: subscribes to kernel events for real-time evaluation
