# Hospital ADT

Admission, discharge, and transfer (ADT) workflow with wards, beds, and inpatient encounter context.

## Domain

- **Ward management**: ward/bed configuration and availability
- **Admission**: inpatient admission from ER or direct
- **Transfer**: bed-to-bed and ward-to-ward transfers
- **Discharge**: inpatient discharge with summary
- **Inpatient context**: encounter extension for inpatient stays
