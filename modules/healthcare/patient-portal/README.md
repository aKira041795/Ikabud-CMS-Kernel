# Patient Portal

Patient-facing portal that releases selected records under consent and audit controls.

## Features

- Patient-accessible appointment view
- Lab results and prescription release
- Document access
- Consent-gated data release
- Audit trail for all patient data access

## Design

The portal surface is intentionally distinct from the admin interface — tables and chrome are simplified for patient use rather than clinical density.
