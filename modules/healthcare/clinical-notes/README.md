# Clinical Notes

Encounter-linked clinical notes with immutable version history, signing workflows, and amendment support.

## Features

- **Immutable history**: each save creates a new version; previous versions are preserved
- **Signing**: notes can be signed (locked) by the author
- **Amendments**: signed notes can be amended with an audit trail
- **Encounter-linked**: always associated with an encounter
