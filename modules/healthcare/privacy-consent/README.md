# Privacy Consent

Consent records and break-glass request logging for restricted EHR access workflows.

## Domain

- **Consent types**: treatment, research, data sharing, patient portal access
- **Consent lifecycle**: granted → revoked → expired
- **Break-glass**: emergency override access with mandatory justification and audit
- **Scope**: per-patient, per-purpose consent management
