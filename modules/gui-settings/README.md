# GUI Settings

Customize frontend appearance — colors, fonts, app name, logo, and visual styling. Provides a settings panel for non-technical users to adjust the look and feel without touching CSS or templates.

## Features

- Color scheme customization (primary, secondary, accent)
- Font selection
- App/tenant name configuration
- Logo upload
- Visual styling presets
