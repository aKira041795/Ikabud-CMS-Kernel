# Theme Studio

Advanced theme customization companion for the CMS. Provides token editor, layout controls, Theme Elements, display rules, pattern import/export, and preset management.

## Features

- **Token editor**: override theme design tokens (colors, spacing, typography)
- **Layout controls**: customize header, footer, sidebar layout
- **Theme Elements**: drag-and-drop element configuration
- **Display rules**: show/hide elements based on context (page, device, user role)
- **Pattern import/export**: share and reuse design patterns across tenants
- **Preset management**: save and apply complete theme presets
