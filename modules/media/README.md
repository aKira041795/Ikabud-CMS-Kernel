# Media

CMS media library module — manages file uploads, metadata, and media capabilities. Shares the `cms_media` table with the CMS module.

## Capabilities

| Capability | Purpose |
|-----------|---------|
| `media.list@1` | List available media items |
| `media.upload@1` | Upload a new media file |
