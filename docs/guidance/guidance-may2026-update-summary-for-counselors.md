# Guidance System — May 2026 Update Summary
**For counselors and guidance staff — no technical knowledge required.**

---

## What's New and What Changed

### 1. The sidebar menu is easier to read

The left-side navigation has been reorganised to match how counselors actually work:

| Before | After |
|---|---|
| Sessions (label for two unrelated links) | **Scheduling & Records** (the group) |
| Appointments (link) | **Appointments & Scheduling** |
| Session Records (link) | **Clinical Session Records** |
| Resources | **Trackers** |
| Dashboard button "New Session" | **New Appointment** |
| Dashboard table "Recent Counseling Sessions" | **Recently Updated Students** |
| Admin items hidden inside the avatar menu | **Users, Colleges, Forms, Templates, Settings now in the sidebar** |

Nothing was moved or deleted — the same screens and data are still there. Only the labels and menu positions changed to match what you actually see on each screen.

---

### 2. After saving changes, the page updates itself automatically

**Before:** After you created, edited, or changed the status of an appointment, note, document, or session record inside a student's profile, the list would stay frozen. You had to reload the whole page or click away and come back to see the updated information.

**After:** As soon as you save a change in any modal window, the tab you are on refreshes automatically and shows the latest data. No manual page reload needed.

This applies to all student profile tabs:
- Appointments
- Session Records
- Notes
- Documents

---

### 3. Appointment status buttons (Complete / No Show) are time-locked

**Before:** The Complete and No Show buttons were always visible and clickable, even hours before the appointment was due.

**After:** The **Complete** and **No Show** buttons only become active once the scheduled date and time of the appointment has actually been reached. Before that time, the buttons are greyed out with a message explaining why. This prevents accidentally closing out a future appointment.

---

### 4. Appointments can be filtered inside a student's profile

Inside a student's Appointments tab, you can now filter the list by category:

- **All** — shows every appointment
- **Upcoming** — only scheduled/confirmed appointments that have not happened yet
- **Completed (Attended)** — only sessions the student attended
- **Did Not Show Up** — appointments the student missed
- **Cancelled** — cancelled appointments

This makes it much quicker to find the specific history you are looking for without scrolling through the full list.

---

### 5. Session detail panel is wider and less cramped

When you click on a session record in the Session Records tab, the detail panel that appears on the right side of the screen is now wider. Session notes, dates, and other details have more space and are easier to read.

---

### 6. Your selected session stays selected when the list refreshes

If you are reading a session's details on the right side and an automatic refresh happens (for example, after saving a note), the system will re-select and re-display that same session for you. You no longer lose your place.

The same behaviour applies to the Notes tab — if you are reading a note and a refresh occurs, the note you were viewing stays open.

---

### 7. Administration settings are now in the sidebar

Previously, several important settings — such as managing counselor accounts, configuring colleges, and adjusting module settings — were only reachable by clicking the user avatar at the top right.

These are now listed directly in the sidebar under a clearly labelled **Administration** group. You no longer need to know to look inside the avatar menu to find them.

---

## Quick Reference — Where Things Are Now

| Task | Where to go |
|---|---|
| Schedule a new appointment | Sidebar → Scheduling & Records → Appointments & Scheduling → New Appointment |
| View a student's full appointment history | Students → (open student) → Appointments tab |
| Mark an appointment complete or as a no-show | Students → (open student) → Appointments tab → open the appointment (button only appears after the scheduled time) |
| View completed and attended sessions | Students → (open student) → Session Records tab |
| Add or edit a counseling note | Students → (open student) → Notes tab |
| Upload a document | Students → (open student) → Documents tab |
| Manage counselor accounts | Sidebar → Administration → Users |
| Manage colleges | Sidebar → Administration → Colleges |
| View and manage student trackers | Sidebar → Trackers |

---

*If you notice anything behaving differently from this description, please report it to your system administrator.*
