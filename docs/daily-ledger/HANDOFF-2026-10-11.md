## 4. TRAPS PAID FOR IN THIS SESSION — do not repeat

1. **Never measure while a lane is live.** I did it twice and drew a wrong conclusion each time
   (a "removed" condition that was mid-write). Check `ps -eo args | grep '[l]ane-name'` first.
2. **A lane's log is not its report.** `lane_model_run` writes the model's output to
   `<log-prefix>-<model>.log`; `.ai/runs/<lane>.log` is the WRAPPER's log and holds PTY noise. A
   complete 7 KB review was recorded as `reason: no_report` because of this. `docs/reviews/` now holds
   the recovered reports.
3. **`reason: timeout` / `state: unverified` / "treat as a crash" are frequently FALSE.** Lanes have
   done their work, committed it, and been recorded as crashed. Verify by content.
4. **Never pipe a lane dispatch.** Piping through `tail` made the tool re-execute the command in a
   second terminal: two lanes, one run name, one tree lock, one session killed.
5. **`git status --porcelain` reports `M` on an mtime-only touch.** Use `git diff --quiet` or compare
   content counts between `git show HEAD:<file>` and the worktree.
6. **Never let a probe swallow its own error.** My C2 claim that the production ledger was empty came
   from a try/catch that printed the error path as `rows=0`. Sol falsified it: 447 rows exist. That is
   the same lying-stat failure this work exists to eliminate, committed by my own tooling.
7. **Do not attach a fallback to a piped command and trust its silence.** `ls … | head || echo "(none)"`
   can never fire, so *missing* and *empty* are indistinguishable.
8. **A check can be wrong in the direction that looks like a finding.** Twice: a criterion asserting on
   rendered HTML for a *conditional* marker (false red), and a criterion comparing two scopes that
   could not differ (all 5355 rows sit in `area_id=2`). Measure every criterion RED on the unchanged
   tree first; if it passes there, it discriminates nothing.
9. **Re-anchoring a stale oracle can delete the requirement.** When fixing the period-comparison
   criterion, the re-anchor also needed a NEW check asserting the opposite case, or it would have
   removed the guard the honesty repair existed to create.
10. **DiSyL:** a bare `{` in CSS/JS is a tag boundary and swallows a closing block tag — wrap in a
    literal wrapper, and never write that wrapper's own tag name inside a comment. A `conic-gradient`
    on a square renders as a fan, not a pie; `border-radius` needs `!important` here.
